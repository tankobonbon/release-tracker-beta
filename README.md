# Tankobonbon Follow Shelf

A tiny Next.js app for Vercel.

## What it does
- Loads Shopify collections
- Lets the visitor follow some of them
- Saves follows and dismissed products in the browser (no login)
- Shows products created in the last 90 days from followed collections

## Required environment variables
- SHOPIFY_STORE_DOMAIN
- SHOPIFY_STOREFRONT_TOKEN

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000
