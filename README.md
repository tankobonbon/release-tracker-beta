# Tankobonbon Release Tracker

A tracker for manga releases that acts as an extension for Tankobonbon's database.

## Link: tracker.tankobonbon.com

## Notes
This is a beta release to materialize the idea I have in mind. There are plenty of books not yet added to the site and series that are not yet configured for this tracker so it's still unfinished, but already usable.

## How to use:
- Search books first, follow the series you want, then head to Releases to mark titles as pre-ordered or dismiss them.
- Clicking on books will direct you to the Tankobonbon page where you can see more book information and view links to pre-order them.
- Everything is stored only in this browser. Open it on another device or browser and your list will be empty there. Also, if you have a lot of books it might take a while for everything to load.
- Unfollowing series will remove them from Releases and pre-order pages.
- Want a hard reset? Clear this site’s cache or site data.

## What it does
- Loads Tankobonbon collections/series
- Lets you follow selected series
- Saves follows, dismissals, and pre-orders in your browser (no login)
- Shows upcoming books from followed collections
- Allows dismissing or marking books as pre-ordered

## Features
- Mobile-friendly with swipeable pages and share support
- Toggleable dark mode
- Scrollable titles in case it's very long (as recent light novels do)
- Search and filtering across books
