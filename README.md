# Tankobonbon Release Tracker

A tiny Next.js app for Vercel that acts as an extension for Tankobonbon's database.

## Notes
This is a beta release to materialize the idea I have in mind. There are plenty of books not yet added to the site and series that are not yet configured for this tracker so it's still unfinished, but already usable.

## What it does
- Loads Tankobonbon collections/series
- Lets you follow selected series
- Saves follows, dismissals, and pre-orders in your browser (no login)
- Shows upcoming books from followed collections
- Allows dismissing or marking books as pre-ordered

## Features
- Mobile-friendly with swipeable pages and share support
- Toggleable dark mode
- Scrollable titles in case it's very long (as recent light novels do)
- Search and filtering across books
